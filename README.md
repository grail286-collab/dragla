# Логово дракона — сервер игры по сети

Маленький сервер на Node.js: комнаты с кодом из 4 цифр, лобби, готовность, старт партии
и рассылка ходов всем игрокам в одном порядке. Саму игру считает каждый телефон —
сервер только раздаёт общее «зерно» случайности и действия игроков, поэтому нагрузка минимальная.

## Запуск на Render (бесплатно)
1. Создай репозиторий на GitHub и положи в него файлы этой папки:
   `server.js`, `package.json`, `package-lock.json`, `render.yaml`, `README.md`.
2. Зайди на https://render.com → **New → Blueprint** и выбери этот репозиторий
   (Render прочитает `render.yaml` и сам создаст сервис `dragon-lair-server`, тариф Free).
   Вручную тоже можно: **New → Web Service**, Runtime **Node**, Build `npm install`, Start `npm start`, Instance **Free**.
3. Дождись статуса **Live** и открой адрес сервиса, например `https://dragon-lair-server.onrender.com` —
   должна появиться строка «Логово дракона: сервер работает».
4. Если адрес получился другим (имя было занято), впиши его в игре: в `game/dragon.html` найди
   `wss://dragon-lair-server.onrender.com` и замени на свой адрес (начало `wss://` вместо `https://`),
   затем пересобери игру: `python3 tools/build.py all`.

## Как проверить без публикации
```
npm install
npm start                      # сервер на http://localhost:8080
```
Открой игру в двух вкладках с параметром `?server=ws://localhost:8080`, например
`http://localhost:8000/assets/www/index.html?server=ws://localhost:8080`.

## Что важно знать про бесплатный тариф Render
- Без игроков сервер засыпает через 15 минут; первое подключение будит его примерно за минуту —
  в игре в это время написано «Подключаемся к серверу…».
- Пока идёт партия, сервер не засыпает: его держат сообщения игроков.
- Render может перезапустить бесплатный сервер в любой момент — комнаты и идущие партии при этом
  пропадут. Для запуска для всех лучше перейти на платный тариф (Starter), он не засыпает.

## Настройки (переменные окружения)
| Переменная | По умолчанию | Что значит |
|---|---|---|
| `PORT` | 8080 | порт (Render задаёт сам) |
| `GRACE_MS` | 30000 | сколько ждать переподключения игрока в партии, потом за него играет ИИ |
| `LOBBY_GRACE_MS` | 15000 | сколько ждать игрока, пропавшего из лобби |
