# Логово дракона — сервер игры по сети

Маленький сервер на Node.js: комнаты с кодом из 4 цифр, лобби, готовность, старт партии
и рассылка ходов всем игрокам в одном порядке. Саму игру считает каждый телефон —
сервер только раздаёт общее «зерно» случайности и действия игроков, поэтому нагрузка минимальная.

Игра ждёт сервер по адресу **`wss://dragon-lair.relaxdev.ru`** (проект `dragon-lair` на RelaxDev).

## Запуск на RelaxDev
1. Создай репозиторий на GitHub (или GitVerse / GitFlic / GitLab) и положи в его корень файлы этой папки:
   `server.js`, `package.json`, `package-lock.json`, `README.md`.
2. Зайди на https://relaxdev.ru, зарегистрируйся (на баланс дадут 500 ₽ — это около 15 дней тарифа PRO).
3. Создай проект с именем **`dragon-lair`** и подключи репозиторий.
   Тип сборки — **Node.js** (платформа сама найдёт `package.json` и команды `build` и `start`).
   Ничего настраивать не нужно: сервер читает порт из переменной `PORT` и слушает `0.0.0.0:8080`.
4. Дождись окончания деплоя и открой `https://dragon-lair.relaxdev.ru` —
   должна появиться строка «Логово дракона: сервер работает».
5. Открой игру на двух телефонах → «По сети» → «Создать комнату» на одном и «Войти по коду» на другом.

Если имя `dragon-lair` окажется занято, создай проект с другим именем и замени адрес в игре:
в `game/dragon.html` найди `wss://dragon-lair.relaxdev.ru`, впиши свой и пересобери: `python3 tools/build.py all`.

## Как проверить без публикации
```
npm install
npm start                      # сервер на http://localhost:8080
```
Открой игру в двух вкладках с параметром `?server=ws://localhost:8080`, например
`http://localhost:8000/assets/www/index.html?server=ws://localhost:8080`.

## Полезно знать
- Комнаты и идущие партии хранятся в памяти сервера: при новом деплое или перезапуске они пропадают.
  Обновляй сервер, когда никто не играет.
- Нужна одна копия сервера (1 реплика): все игроки комнаты должны попасть на один и тот же сервер.
- Если игрок потерял связь, у него есть 30 секунд, чтобы вернуться; потом его героем играет компьютер.

## Настройки (переменные окружения)
| Переменная | По умолчанию | Что значит |
|---|---|---|
| `PORT` | 8080 | порт (RelaxDev задаёт сам) |
| `GRACE_MS` | 30000 | сколько ждать переподключения игрока в партии, потом за него играет ИИ |
| `LOBBY_GRACE_MS` | 15000 | сколько ждать игрока, пропавшего из лобби |
